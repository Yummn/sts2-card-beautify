# CardBeautify v0.5.5 PC 实机验证

- 时间：2026-07-28 13:20（Asia/Shanghai）
- 平台：Steam PC v0.107.1
- 场景：主菜单 → 百科大全 → 卡牌总览 → 故障机器人筛选 → 卡牌详情 → 返回卡牌总览
- 最终 PC DLL SHA256：`FB29DBEE60EDAA7CF2B880A0BF03AECCBCB4C89E81ADD9D0535E21816538C636`

## 验证结果

1. 首次打开卡牌总览时，支持替换卡面的卡牌正常显示“卡图：自动”按钮。
2. 切换到故障机器人筛选并等待卡牌行重建后，卡面按钮完整恢复。
3. 打开“双重释放”详情时，详情页没有卡面按钮。
4. 关闭详情后约 250 ms 截图复查，网格内卡面按钮已经自动恢复，没有等待重新打开百科。
5. “改造”和“禁用出率”按钮仍正常，卡面按钮没有泄漏到详情页。

结论：筛选、行重建和详情弹窗导致的临时作用域变化不再删除卡面按钮；按钮会先隐藏并禁用触控，百科网格恢复有效后由自身生命周期立即重新显示。

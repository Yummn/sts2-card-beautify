# CardBeautify v0.5.7

## 修复

- 修复“冰之长枪”部分卡图包在卡框中被居中裁掉人物上沿的问题。
- 修复“偏差认知”竖版卡图在百科详情页中被截成错误中心切片的问题。
- 为两张卡生成并缓存 1.5:1 的焦点裁剪，百科网格、详情页和局内卡牌使用同一张规范化纹理。
- 比例已经匹配卡框的资源直接复用，不产生额外裁剪或每帧重建开销。
- 保留原有逐卡卡图选择文件，不会重置用户设置。

## 安装包

- `卡面美化-v0.5.7-手机-v103.zip`
- `卡面美化-v0.5.7-手机-v110.1.zip`
- `卡面美化-v0.5.7-电脑-v107.1.zip`

解压后把 `CardBeautify` 文件夹放入游戏的 `mods/` 目录。

## 验证

- Android v110.1 / REDMI K80 Pro 实机进入百科大全。
- 验证冰之长枪的 Anime 卡图在网格与详情页中保留人物头部和冰枪主体。
- 验证偏差认知在详情页中同时保留摆锤、头发和面部构图。
- 验证冰之长枪原有 Diana 选择在测试后恢复，持久化文件未被重置。
- v103、v110.1 和 PC v107.1 三套程序集均编译通过，0 警告、0 错误。
